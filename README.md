 # Blinkit Dashboard – Power BI Project
This repository contains a Power BI dashboard developed to analyze and visualize operational and business metrics for Blinkit, an online grocery delivery service. The dashboard is designed to provide key insights for data-driven decision-making.

## 📌 Key Features
Interactive visualizations for performance tracking

KPIs including revenue, number of orders, and average delivery time

Slicers and filters for city, category, and time-based analysis

Drill-through pages for detailed insights at product and regional levels

## Tools & Technologies
Power BI Desktop

DAX (Data Analysis Expressions)

Power Query (M Language)
